# 名画座スケジュール

東京の名画座・ミニシアター21館の上映スケジュールを、各館の公式サイトから集めて1ページにまとめる自分用ツール。

## 使い方(このPCで)

```
npm run update
```

`data/schedule.json` に全館のデータを保存し、`dist/index.html` を作ります。`dist/index.html` をブラウザで開けば見られます。

1館だけ試すとき: `npx tsx src/run.ts waseda`(館のIDは `src/theaters/index.ts` を参照)

## しくみ

- `src/theaters/*.ts` … 館ごとの読み取りプログラム。サイトの作りが変わったらここを直す
- `src/run.ts` … 全館を順に読む。失敗した館は前回のデータを残し、ページに「取得失敗」と出す
- `src/build.ts` + `site/template.html` … データをページに埋め込む
- `.github/workflows/update.yml` … GitHub で毎朝6時に自動実行する設定

| 取り方 | 館 |
|---|---|
| チケットシステムのデータ | K's cinema・Stranger・ポレポレ東中野(映画ランド)、K2(box-office)、シネマリス、キネカ大森(TTCG)、ル・シネマ(Bunkamura チケット) |
| サイトの裏のデータファイル | 神保町シアター、東京日仏学院(イベント一覧のAPIから東京の映画イベントを探し、各ページを読む) |
| ページのHTMLを読む | 早稲田松竹、新文芸坐、目黒シネマ、ラピュタ阿佐ヶ谷、シネマヴェーラ、下高井戸シネマ、国立映画アーカイブ、アテネ・フランセ文化センター(特集ごとのページ)、ユーロスペース、イメージフォーラム、ブルースタジオ |
| 画像を Claude に読ませる | Morc阿佐ヶ谷(環境変数 `ANTHROPIC_API_KEY` が必要。同じ画像は二度読まない) |
